# Staffly

React + TypeScript + Vite, Express API, PostgreSQL и Prisma.

## Структура

- `src/pages/app/` — интерфейс по рабочим модулям: организации, главная, сотрудники, настройки, расписание, заявки, документы и события.
- `src/pages/app/shell/` и `topbar/` — оболочка авторизованного приложения и шапка.
- `src/pages/app/schedule/` — календарь, отсутствия, планирование, предложения смен, рабочее время, отчёты и статистика в отдельных каталогах.
- `src/pages/app/settings/` — личные настройки, настройки организации и управление доступом.
- `src/pages/app/shared/` — общие элементы рабочих модулей; `src/component/ui/` — общие элементы интерфейса, включая модальные окна.
- `src/app/` — клиентские запросы, hooks, типы и форматирование по предметным областям.
- `src/server/` — API и серверные сервисы. Почта — `mail/`, права организаций — `organizations/access/`, части расписания — `schedule/{planning,reports,time}/`.
- `tests/` — проверки по предметным областям; `tests/helpers/` — общие fixtures.
- `prisma/` — схема и миграции; `scripts/` — служебные команды.
- `output/` — согласованные макеты и результаты визуальной работы, сгруппированные по задачам.

Компонент и его стили хранятся рядом. Новые файлы добавляйте в соответствующий модуль, а общие компоненты — в существующие общие каталоги. URL страниц и API не зависят от расположения исходников.

## Команды

```sh
npm run dev:all  # Vite на 5173 и API на 3001
npm run lint
npm run build
npm test
```

Для тестов нужна отдельная тестовая БД из `src/server/.env.test`; runner использует временное файловое хранилище. Конфигурация окружения остаётся в `src/server/`, точки входа и npm-команды — в прежних местах.
