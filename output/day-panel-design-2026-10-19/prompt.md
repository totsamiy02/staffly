## Итоговый запрос генерации

Use case: ui-mockup. Create a polished, production-ready redesign proposal collage for the Staffly employee scheduling web app, using the attached screenshot ONLY as a reference for the existing content and calm monochrome visual language. This is a NEW redesigned UI concept, not an annotation of the screenshot. All visible interface text must be legible, correctly spelled Russian.

Deliver ONE large landscape design board with TWO complete views side by side: left a desktop right-side day-details panel, right its mobile bottom-sheet adaptation. Modest labels above: "На компьютере" and "На телефоне". Render the full usable interfaces including their bottom actions. No devices, no tilted screens, no marketing copy, no decorative graphs, no exploded views, no code. Crisp flat front-on UI, realistic Figma-quality spacing, vector-like line icons, Arial/Inter-like sans serif, subtle light gray dividers, white cards, rounded 14–18px corners, black primary actions and very restrained muted purple for the user's own shift. Warm off-white presentation background. The desktop view can show a narrow subdued blurred calendar background behind the right-anchored panel to explain context. Avoid the enormous empty white space of the reference: the desktop panel should fit its content, floating near the upper-right with modest outer margins, roughly 520px equivalent width and 640px equivalent height, not stretch a mostly empty card to the bottom of the screen. Mobile is a natural-height sheet with a subtle drag handle and rounded top corners, around 390px equivalent width. Make the entire collage large enough to read.

Preserve the actual functions from the reference. Both views should depict the SAME single completed shift on October 16, 2026. Header: small eyebrow "РАСПИСАНИЕ НА ДЕНЬ", a clear date "16 октября 2026", subtitle "Пятница · Основная точка", accessible close X at upper-right. Below a compact two-option segmented tab "Смены · 1" (selected) and "Потребность" (inactive), no horizontal scrolling.

Main shift card: circular employee avatar (can use a cropped stylistic avatar from the reference), the name "Биленко Ярослав" and second line "Александрович", muted own-shift tag "Ваша смена", neutral small status chip "Завершена". Show the position "Повар холодного цеха" with a small outline briefcase icon. Create an elegant lightly shaded time summary inside the card, with two clearly aligned columns: "По плану" over bold "09:00–22:00", and "К учёту" over bold "13 ч". Under it, small helpful text "По расписанию, без корректировок". This wording is important: do NOT falsely label planned hours as verified attendance. Then an obvious outlined pencil button "Исправить время". Avoid a thick purple outline around the entire card, avoid vertical colorful stripes.

At the bottom of each panel, group the two day-level actions in a restrained footer separated by a subtle divider: black primary full-width button with plus icon "Добавить смену"; smaller secondary outline action with people icon "Создать заявку на подмену". Keep these distinct from editing an existing shift. Comfortable touch targets, no clipped or truncated names, no tiny illegible labels, no huge vertical gaps. The desktop and mobile designs must visibly share the same component system and exact data. The mobile layout should wrap naturally, never squeeze side-by-side controls beyond readable sizes. No invented extra functionality or unrelated notifications.
